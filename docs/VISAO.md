# Visão Geral do Projeto — Crimson Veil

## 1. Visão

Crimson Veil é um universo ficcional de investigação policial, suspense e mistério que está sendo expandido para uma experiência digital interativa.

## 2. Objetivo

Transformar o universo de Crimson Veil em um sistema investigativo digital capaz de organizar e conectar informações relacionadas a investigações.

## 3. Conceito

O sistema deve funcionar como uma plataforma profissional utilizada por investigadores dentro do próprio universo.

## 4. Experiência

A experiência deve combinar:

* Investigação policial;
* Suspense;
* Tecnologia;
* Mistério;
* Organização;
* Imersão.

## 5. Princípios

O projeto deve priorizar:

* Investigação;
* Descoberta;
* Organização;
* Conexão entre informações;
* Consistência;
* Clareza;
* Manutenção;
* Escalabilidade.

## 6. Idioma

O português é o idioma padrão do projeto em documentação, interface, textos, mensagens, comentários e nomenclaturas de domínio.

## 7. Desenvolvimento

* O projeto será desenvolvido de maneira incremental.
* O MVP deve conter somente as funcionalidades necessárias para validar o conceito principal.
* Funcionalidades futuras não devem ser implementadas prematuramente.
