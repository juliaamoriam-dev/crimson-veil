# Crimson Veil

Crimson Veil é um universo ficcional de investigação policial, suspense e mistério que está sendo expandido para uma experiência digital interativa por meio de um sistema profissional de investigação.

> **Aviso:** O projeto encontra-se em **fase inicial (Fase 0 — Fundação)**. Nenhuma funcionalidade ou código de aplicação foi implementado ainda.

---

## Objetivo

Transformar o universo de Crimson Veil em um sistema investigativo digital capaz de organizar e conectar informações relacionadas a investigações (casos, pessoas, locais, pistas, evidências, documentos e linhas do tempo).

---

## Estado Atual do Projeto

* **Fase:** FASE 0 — Fundação
* **Situação:** Estruturação documental e preparação do workspace. As definições detalhadas de produto, requisitos, arquitetura e tecnologias serão realizadas nas fases seguintes.
